# 📌 Multiple Linear Regression Model – Advertising Dataset

This project implements a **Multiple Linear Regression (MLR)** model to predict **Sales** based on advertising budgets: TV, Radio, and Newspaper.  
It demonstrates data preprocessing, model training, evaluation, and making predictions in Python using scikit-learn.

---

## 🚀 Project Overview

The dataset contains information about advertising budgets across three channels:

- TV Advertising Budget  
- Radio Advertising Budget  
- Newspaper Advertising Budget  

The goal is to predict **Sales** using these features.

This beginner-friendly ML project covers:

- Data cleaning  
- Feature/target selection  
- Linear Regression model  
- Model evaluation  
- Making predictions  

---

## 📊 Model Workflow

1. Load dataset (`advertising.csv`)  
2. Convert data into appropriate format  
3. Split into features (`X`) and target (`y`)  
4. Fit Multiple Linear Regression Model  
5. Evaluate model using metrics  
6. Make predictions using a prediction function
